# CaseShield Validation MVP

Premium 2026 smoke-test website for validating demand for U.S. immigrant visa disruption intelligence.

**Live:** https://caseshield-validation.vercel.app/

## Validation funnel
- page_view
- hero_cta_click
- case_check_started
- case_step_1 ... case_step_5
- case_check_completed
- alert_intent
- pricing_view
